# 三进制完备

用**平衡三进制**（−1 / 0 / +1）从零重建计算机的网页闯关游戏：
从一个 TNAND 门出发，经阈值门、MUX、加法器、寄存器、内存、ALU，
最终在 TRIT-3 CPU 上写汇编。共 25 关，中英双语。

English version: [README.md](README.md).

## 开始玩

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

纯静态文件，无需构建，无依赖。

## 玩法

- **任务路线**：布线台式的科技树，自下而上，关卡用导线蛇形连起来。点节点进入布线台。
- **布线台**：从钉拖到对端钉连线（正反向都行，靠近 28px 自动吸附，落在元件本体
  接最近的空闲钉），拖已连线的输入钉可改接或断开，元件箱可直接拖到画布，
  按住导线拖拽改走向，双击加节点，右键删除，框选，多选搬移，平移缩放，`F` 适应画布，
  撤销/重做，复制粘贴。所有元件钉位都在 22px 网格上，走线天然对齐。
- **布线规矩**：不同网络的导线只许交叉、不许重叠或贴靠（平行间距 <6px 且并行 >24px
  同样拦截）。同一输出出发的分叉线可以共用主干，分叉处画焊点。
  违规落线自动挤到旁边空位，实在没空位才回退上一步。
- **时钟**：单步滴答 + 自动档（1/2/5/10 TPS）+ 拍计数，左上输入输出总览条，
  下方信号时间轴逐拍采样波形。
- 每关工具条都有「参考解」按钮：载入已验证的完整做法并自动跑测试。
- 「开发者模式」（全关解锁）只在本机调试时出现（localhost 或本地文件，网址加 `?dev` 也行），发布到线上自动关闭。

- 云存档：进度、每关电路和汇编代码跟随 B站账号，换设备自动恢复（与本地按每关时间合并）
- 排行榜：通关数榜、精简分榜（比参考解用更少的元件得分更高），总榜 / 本周 / 今日

- B站账号头像昵称、App 安全区适配、手机竖屏提示切横屏，触屏单指平移 / 双指缩放

核心一课：单个 TNAND 在三值逻辑里**不完备**（它能表达的函数全是保零的）。

而建立在阈值门上的 MUX 让任何真值表都变成查表。

## 目录说明

- `index.html` ：路线图独立页 + 全屏布线台 + 底部测试条 + 弹窗
- `styles.css` ：全站样式（UI 铬零圆角，标准逻辑符号按 ANSI 绘制）
- `ternary.js` ：三值逻辑核心，十进制与平衡三进制互转
- `levels.js` ：元件定义（`COMP_DEFS`）+ 25 关（`LEVELS`，中文）
- `levels_en.js` ：关卡/章节/元件名的英文覆写
- `i18n.js` ：界面语言字典（中英双份）、`t()` 取词、语言切换
- `icons.js` ：内联 SVG 图标库（全项目唯一图标来源，不用 emoji）
- `editor.js` ：电路编辑器 + 仿真器（求值/滴答/测试/序列化/走线器）
- `solutions.js` ：全部关卡的已验证参考解（电路规格 + 汇编程序）
- `cpu.js` ：TRIT-3 CPU（3-trit 字，R0-R3，M0-M8）
- `app.js` ：视图切换、验证台、CPU 面板、存档（`localStorage`）
- `scripts/check_solutions.js` ：全关参考解 headless 回归
- `scripts/check_terms.py` ：名称检测，挂在 pre-commit 上每次提交自动跑
- `AGENTS.md` ：协作规范（提交工作流、UI 约束、常用命令）
